# AI 수업 렌즈

AIEDAP 마스터교원 연수 · 우수사례 탐험 (17·18회, 2025, 20회 연구대회 사례를 여섯 가지 렌즈와 세 번의 의사결정 지점으로 살펴보는 정적 웹페이지).

- `index.html` — 앱 전체 (HTML·CSS·JS 한 파일, 빌드 없음)
- `apps-script/Code.gs` — 연수 중 선택(A~D)을 구글 시트에 모으는 구글 앱스 스크립트
- `apps-script/AI수업렌즈_연수응답집계.xlsx` — 응답·집계 시트 (구글 드라이브에 올려 스프레드시트로 열기)

## 의견 모아 보기 켜기
1. 엑셀 파일을 구글 스프레드시트로 열고, 확장 프로그램 → Apps Script에 `Code.gs`를 붙여넣기
2. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
3. 나온 웹 앱 URL을 `index.html`의 `const SURVEY_URL="";` 에 넣고 커밋
